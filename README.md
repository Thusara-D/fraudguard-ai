
# FraudGuard AI

Real-Time Financial Fraud Detection &
Intelligent ML Monitoring Platform

## Project Overview

FraudGuard AI is an end-to-end machine
learning project designed to identify
potentially fraudulent financial transactions.

## Objectives

- Analyze financial transaction data
- Train and compare ML models
- Predict fraud probabilities
- Explain model predictions
- Build a real-time prediction API
- Create a fraud monitoring dashboard
- Monitor model performance and data drift

## Technology Stack

- Python
- pandas and NumPy
- scikit-learn and XGBoost
- MLflow
- FastAPI
- PostgreSQL
- Streamlit
- Docker

## Dataset

PaySim — Synthetic Financial Datasets
for Fraud Detection
